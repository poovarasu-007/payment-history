Import bank statement (CSV / Excel-exported / pasted data)

A UPI ID alone cannot read your bank history. Export a statement (CSV) from your bank or UPI app, or paste spreadsheet rows below. The importer auto-detects columns, matches your configured UPI IDs, removes duplicates by UTR/reference and stores everything in All Transactions.

Manual transaction entry

Use this only for corrections or sources you cannot export. Every manual entry is labelled Manual Entry and recorded in the audit log.

🔒 Never enter a UPI PIN, OTP or banking password anywhere in this app. It will never be requested.

Export & reports

CSV files open directly in Excel / Google Sheets. Transaction exports respect the filters set on the All Transactions tab. Printable reports open your browser's print dialog.

Reconciliation report

Flags missing references, duplicate candidates, refunds/reversals, amount mismatches and unknown directions. Nothing here is changed automatically.

Registered UPI IDs

Enable or disable each ID for transaction matching. These are identifiers only — they are not credentials and cannot read bank history by themselves.

Data source & synchronization

Optional: connect an authorized provider webhook that returns statement rows in the supported CSV format. This app never scrapes protected banking pages and never bypasses UPI/bank security. Tokens are stored server-side in Script Properties and are never sent to the browser.
